# 坦克大战 - Tank Battle Game

一个基于HTML5 Canvas的经典8位像素风格坦克大战游戏。

## 游戏特性

- 🎮 经典8位像素风格设计
- 🎯 流畅的WASD移动和鼠标瞄准射击控制
- 🤖 智能AI敌人，具有追踪、攻击和躲避行为
- 💥 炫酷的爆炸效果和子弹轨迹
- 🏆 波次系统，难度递增
- 💖 生命值系统和计分系统
- ⚡ 60FPS流畅游戏体验

## 如何运行

### 本地运行

1. 确保你有一个现代浏览器（Chrome、Firefox、Safari等）
2. 下载或克隆此仓库
3. 打开 `index.html` 文件即可开始游戏

### GitHub Pages部署

项目已配置为可部署到GitHub Pages：

1. Fork此仓库到你的GitHub账户
2. 在仓库设置中启用GitHub Pages
3. 选择main分支作为源
4. 访问生成的链接即可游玩

## 游戏控制

- **W/A/S/D** - 移动坦克
- **鼠标** - 瞄准方向
- **鼠标左键** - 发射子弹
- **暂停按钮** - 暂停/继续游戏

## 游戏规则

1. 控制绿色坦克（玩家）对抗红色敌人坦克
2. 每个敌人有100点生命值，你的子弹造成25点伤害
3. 敌人的子弹造成20点伤害
4. 初始生命值为100点
5. 消灭所有敌人进入下一波，敌人数量会增加
6. 生命值降为0时游戏结束

## 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计（含响应式布局）
- **JavaScript** - 游戏逻辑（ES6+）
- **Canvas API** - 游戏渲染
- **Git** - 版本控制

## 开发说明

### 代码组织

游戏采用面向对象的设计模式：
- `Tank` 类 - 玩家和敌人的基础行为
- `Bullet` 类 - 子弹逻辑和渲染
- `InputManager` 类 - 输入处理
- `Game` 类 - 游戏整体管理

### 性能优化

- 使用 `requestAnimationFrame` 实现60FPS
- 对象池模式减少内存分配
- 高效的碰撞检测算法
- 画布渲染优化

## 自定义和扩展

### 添加新功能

1. **新武器类型**：修改 `Bullet` 类
2. **新敌人类型**：继承 `Tank` 类
3. **新游戏模式**：扩展 `Game` 类
4. **音效系统**：添加 Web Audio API 支持

### 自定义样式

编辑 `css/style.css` 文件来自定义游戏外观。
